## Game Proposal ## 
We will create a digital version of the classic 10X10 board game called Snakes and Ladders.
In this game players will take turns rolling a die to move across a numbered grid from start to finish.
If the player lands on the bottom of a ladder, they climb to where the top of the ladder is. 
Otherwise, if they land on the head of a snake, they go down to the snake's tail.
The goal is to be the first player to reach the final square. 
We will include multiple players, animation/graphics, and a simple GUI board. 


The game is snakes and ladders. There will be a 10x10 boards with each square being numbered from 1-100. There are snakes on some squares and ladders on others. The mouth of a snake would bring the player down to the end of the snake(which would be a tile). If the player reaches a square with a ladder, the player would climb up to the ladder to a higher square. Reaching the 100th square would end the game(win).

Game Controls:
- Press a button or space bar to roll the dice 
- Players move automatically based on the roll
- Mouse clicks for menu options 

Game Elements:
- Numbered board (from 1 to 100 grid)
- 2-4 players
- Dice rolling system (1-6)
- Snakes (move players down)
- Ladders (moves players up)
- Turn based system
- Win screen 
- Menu Page


How to Win:

- Be the first player to reach the final square
